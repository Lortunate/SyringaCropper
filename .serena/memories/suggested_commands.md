On Windows in this repo, use Git Bash. Common commands: `./gradlew tasks`, `./gradlew build`, `./gradlew test`, `./gradlew :cropper:test`, `./gradlew :cropper-processor:test`, `./gradlew :example:assemble`, `./gradlew :androidApp:assembleDebug`, `git status --short`, `git diff --stat`, `git add <paths>`, `git commit -m \"type(scope): message\"`. Prefer `rg` for search and `rg --files` for file listing.
