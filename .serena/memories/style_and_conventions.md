Build scripts use Kotlin DSL (`*.gradle.kts`) with version catalog aliases from `gradle/libs.versions.toml`. Codebase structure follows Kotlin Multiplatform source set conventions (`commonMain`, `androidMain`, `jvmMain`, `wasmJsMain`, etc.). Naming follows standard Kotlin conventions with PascalCase types and camelCase members. Repositories and plugins are centralized at the root Gradle files.
