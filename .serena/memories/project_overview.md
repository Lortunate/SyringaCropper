SyringaCropper is a Kotlin Multiplatform image cropping project with modules for a reusable cropper library (`cropper`), a processing engine (`cropper-processor`), an example app (`example`), and an Android application module (`androidApp`). The stack uses Kotlin 2.3.20, Gradle Kotlin DSL, Android Gradle Plugin 9.1.1, Compose Multiplatform 1.10.3, Material3, Kotlin serialization, coroutines, and some Rust/JS bridge code under `cropper-processor/rust`. Source sets are split across common, android, jvm, wasm/js, ios/skia/unsupported targets.
